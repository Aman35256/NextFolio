NextFolio AI Career Agent - Product &
Development Prompt
Build a new module inside NextFolio called AI Career Agent.


IMPORTANT:


     • Keep the entire frontend design system, color palette, typography, navigation, dashboard layout,
       responsiveness, animations, and user experience identical to the existing NextFolio platform.
     • This is an enhancement to NextFolio, not a separate application.
     • The new feature must seamlessly integrate into the current architecture.


Vision
Create a fully autonomous AI-powered career agent that continuously searches, evaluates, applies, tracks,
and manages job opportunities worldwide on behalf of the user.


The user should only upload their resume once and configure preferences. After that, AI agents handle the
complete job-hunting lifecycle.
