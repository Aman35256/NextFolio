# Resume Action Verbs Guide

Use these strong action verbs at the beginning of bullet points to convey impact and ownership.

## 1. Technical & Engineering
- **Developed**: Built software products, architectures, or backend services.
- **Architected**: Designed high-level systems, data pipelines, or server infrastructure.
- **Engineered**: Solved complex technical problems or optimized algorithms.
- **Implemented**: Deployed code, frameworks, or security protocols.
- **Integrated**: Connected external APIs, microservices, or databases.
- **Refactored**: Rewrote codebase structures to improve code cleanliness and maintainability.

## 2. Leadership & Management
- **Led**: Guided teams, projects, or sprints.
- **Mentored**: Coached junior engineers, leading to promotion or skill growth.
- **Orchestrated**: Coordinated cross-functional initiatives across design, product, and engineering.
- **Spearheaded**: Initiated and directed key technical migrations or features.
- **Fostered**: Created positive workflows, collaboration, or code review policies.

## 3. Optimization & Impact
- **Optimized**: Improved speed, performance, SQL query times, or UI rendering.
- **Accelerated**: Reduced project timelines or deployment cycles.
- **Minimized**: Decreased server costs, latency times, or bug counts.
- **Quantified**: Calculated metrics, tracking KPIs and growth percentages.
- **Streamlined**: Simplified workflows, continuous integration, or automation tooling.
